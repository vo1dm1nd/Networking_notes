## Client Server Roles

> Client = A client is a computer hosts which enables the hosts to reequest and display the information obtained from the server.

> Server = Servers are hosts which provide information like email, web page to other hosts on the network.

## Peer to peer Networks
> In P2P network the same host is a client and a server at the time.

## Network Infrastructure 
> The network infrastructure contains three hardware components.
- End Device
- Intermediate Device 
- Network Media

### End Devices 
> The devices that people are most familiar with are called end devices. Such as Mobile, computers, laptops, tablets, Security Cameras ..etc
