# Wireless Connectivities

### 1. GPS 
- Global Positioning System = it uses satellites to transmit signals to cover the globe. These signals covers and calculate the phone's location to and accuracy of 10 meters.

### 2. Wi-Fi
- Wi-Fi transmitters and recievers in the smartphone enables the phone to the internet & local networks.

### 3. Bluetooth 
- Bluetooth is a wireless technology that allows devices to communicate over short distance and multiple devices can be connected at same time.

### 4. NFC 
- Near Field Communication (NFC) it uses electromagnetic fields to transmit data and it is mostly used in smarthphones for payment system.

## Mobile Devices Connectivity
### Precautions to protect wifi communications
- Never send login or passwd information using unencrypted text.
- Use a VPN connection when possible if you are sending sensitive data.
- Enable security on home networks.
- Use WPA2 or higher encryption for security.
